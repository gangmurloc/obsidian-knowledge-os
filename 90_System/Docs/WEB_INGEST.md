# Web Ingest

## Outcome

Obsidian Web Clipper creates one canonical Markdown source note in `30_Resources/Sources/Web/`. The source note contains the captured article, not an AI summary. AI interpretation belongs in a separate note under `30_Resources/AI-Wiki/`.

HTML files do not need to be retained in v1. Markdown is the canonical working representation, and `source_url` preserves where it came from.

## Manual Web Clipper Setup

1. Install the official Obsidian Web Clipper extension from the browser's official extension store.
2. Open Web Clipper settings and connect/select the `GIL` Vault.
3. Create a new template named `Gangil Web Source`.
4. Set behavior to **Create a new note**.
5. Set note location to `30_Resources/Sources/Web`.
6. Set note name to `{{title}}`. Review the name before saving when the page title is empty or unsuitable.
7. Add the property mappings listed in [[90_System/Prompts/Web Source Template|Web Source Template]].
8. Paste the documented body template into the template's note-content field.
9. Keep Interpreter disabled. Do not use prompt variables such as `{{"summarize this page"}}` in v1.
10. Capture a test article and verify its filename, URL, author, publication date, capture date, and article content before routine use.

The preset variables in this workflow are documented by Obsidian: `{{title}}`, `{{author}}`, `{{url}}`, `{{published}}`, `{{date}}`, and `{{content}}`. The `date` filter supports `YYYY-MM-DD` formatting.

## Required Metadata

| Property | Value |
| --- | --- |
| `type` | `source` |
| `origin` | `external` |
| `source_type` | `web` |
| `knowledge_status` | `raw` |
| `title` | `{{title}}` |
| `author` | `{{author}}` when available |
| `source_url` | `{{url}}` |
| `published` | `{{published}}` formatted as `YYYY-MM-DD` when available |
| `created` | capture date from `{{date}}`, formatted as `YYYY-MM-DD` |
| `updated` | same as `created` at capture time |
| `domain` | empty list until classified by a person |
| `human_verified` | `false` |

Do not invent missing author or publication data. A blank field is more accurate than a guessed value.

## Content Boundary

- `## Content` contains `{{content}}`, the article body, selection, or highlights returned by Web Clipper.
- `## My Highlights` is reserved for the user and remains empty on initial capture.
- Do not insert an AI summary, interpretation, tags, or inferred domain into the Source note.
- Preserve the URL in both `source_url` and the visible `## URL` section.
- Save author and published date when the page exposes them.
- If extraction omits important content, use a deliberate selection or site-specific selector only after verifying the result.

## Validation Checklist

- The note is under `30_Resources/Sources/Web/`.
- The note opens as valid Markdown in Obsidian.
- `source_url` is present and matches the captured page.
- Original article content is under `## Content`.
- No AI-generated summary appears in the Source note.
- Missing metadata remains blank rather than inferred.
