# Memory Note

> AI-generated knowledge. Verify against original sources before treating as understood.

## Definition

A structured memory unit constructed from agent interactions that captures explicit content, timestamps, and LLM-generated semantic components including keywords, tags, contextual descriptions, and linked memories.

## Core Idea

Transforming raw agent interactions into atomic, semantically enriched notes using LLMs to facilitate flexible organization and efficient retrieval.

## Mechanism

The process involves prompting an LLM with templates to analyze interaction content and generate keywords, tags, and contextual descriptions. These components are combined with the original content and timestamp to form a structured note. A text encoder then computes a dense vector representation of all textual components to enable similarity matching and linking.

## Key Points

- Notes follow Zettelkasten principles of atomicity, capturing single self-contained units of knowledge.
- LLMs generate semantic components (keywords, tags, context) to enrich raw interaction data.
- Each note includes a set of linked memories sharing semantic relationships.
- Dense vector representations are computed via text encoders for efficient retrieval.
- The structure enables autonomous extraction of implicit knowledge from interactions.
